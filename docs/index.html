Formalizing CPython

A machine-checked model of the CPython interpreter and standard library, written in Lean 4 the way julia-in-lean models Julia Base. Every function, opcode and grammar rule is listed. Each one counts as covered only after an independent review confirms that its model mirrors the C or Python source and that its theorem would catch a wrong implementation.

How a row gets covered

  1. Mirror the source. The Lean model follows the C or Python body line by line: the same branch order, the same early returns, the same error messages, Py_ssize_t narrowing and fast paths. Every step cites Objects/<file>.c:<lines> in the 3.15.2 tree.
  2. Test it against the interpreter. A differential test runs the Lean model and python3 3.15.2 on the same generated inputs, with callbacks that raise and re-enter, until they agree on at least 50,000 cases over several seeds.
  3. State and prove a property. Each property is quantified over all inputs, with no sorry, no native_decide and no new axioms. A statement that turns out to be false is refuted in Lean with a witness and recorded, never weakened into something provable.
  4. Survive an independent review. A separate reviewer asks whether a wrong function would still satisfy the theorem (one that always raises, or handles only the first branch) and probes every claim on the real interpreter. Rows marked FAITHFUL count. Rows marked HOLLOW are withdrawn until fixed.

Review is the number that matters. The project counts reviewed rows, not claimed ones: 4,516 registered properties (94 still open) back fewer covered rows than the authors claimed, because reviews keep withdrawing statements that a wrong implementation would also satisfy.

A theorem from the model

The length of range(start, stop, step) is computed in C on a fast path over long and a slow path over Python ints. This property pins all three length functions to the same exact count, so a slow path that returned 0, or a fast path that always overflowed, would fail it.

def RangeLengthExact : Prop :=
  (∀ lo hi step : Int, IsLong lo → IsLong hi → IsLong step → step ≠ 0 →
    IsLen lo hi step (getLenOfRange lo hi step)) ∧
  (∀ start stop step L : Int, step ≠ 0 → IsLen start stop step L →
    computeRangeLengthLong start stop step =
      if IsLong start ∧ IsLong stop ∧ IsLong step ∧ L ≤ longMax then some L else none) ∧
  (∀ start stop step : Int, step ≠ 0 →
    IsLen start stop step (computeRangeLengthSlow start stop step)) ∧
  (∀ start stop step : Int, step ≠ 0 →
    IsLen start stop step (computeRangeLength start stop step))
